# 场景规则

用户提到视频的用途时，按下表取参数；表里没有的场景，先问清目标平台的大小上限，再用 `--max-size` 留约一半余量。新场景确定后在这里加一行，不改脚本。

| 场景 | 参数 | 依据 |
|---|---|---|
| GitHub（README、Release、issue、PR 里内嵌播放） | `--max-size 5MB`，保持原分辨率；仍超标再加 `--max-height 720` | 平台上限 10 MB，压到 5 MB 以内留出余量、加载更快 |

## GitHub

- 内嵌播放器只对网页上传得到的 `github.com/user-attachments/assets/...` 链接生效：在 issue、PR 或 Release 编辑框里拖入视频取得链接，单独一行放进 Markdown 即可显示播放器。
- 提交进仓库的视频文件在文件页面不会播放（显示 “View raw”），与大小无关；仓库里保存一份原始文件即可，展示走上面的上传链接。
- 刚上传、尚未被公开内容引用的链接，未登录访问会暂时返回 404；写进公开的 README 或 Release 后即可正常访问，发布后用未登录方式核对一次。
- 同一视频若也放在 GitHub Pages 等静态站点上，换文件但不改文件名时会被缓存挡住；在页面里给地址加上内容哈希版本号（如 `video.mp4?v=<sha256 前 8 位>`）。
