Curated agent skills,
ready to install.

Original and collected skills for AI coding agents. Each one is a folder with a SKILL.md; the agent reads its description and invokes it when your request matches.

InstallBrowse skills · 8 skills

Install in three steps

  1. 1

    Install every skill for all your agents (user level, available in every project):

    bash
    npx skills add forsakesoul/awesome-skills -g
  2. 2

    Or pick one skill and one agent, non-interactively:

    bash
    npx skills add forsakesoul/awesome-skills -g --skill video-compress --agent codex -y
  3. 3

    Start a new agent session so it picks up the new skills. Update or remove them later with npx skills update -g / npx skills remove <name> -g.

Concurrently copy photos/videos (ARW/HIF/JPG/...) from a source directory (e.g. an SD card's DCIM folder) to a target subdirectory, recursively, preserving the relative folder structure. Filters by file extension.

batch-image-compress

批量把本地图片上传到 PixelForge 在线压缩站点（或同构服务）压缩，按档位/格式处理后下载到新目录并保留相对结构。默认走服务端接口，--mode ui 可用真实 Chrome 驱动网页。含 md5 秒传、5 分钟 TTL、merge 504 等服务端坑位的绕过方案。

What's a skill?

A skill is a directory with a SKILL.md: YAML frontmatter with a name and a description, plus optional scripts and references. The description tells the agent when to reach for it, so you just ask in your own words.

Contributing

One skill per top-level directory, a portable SKILL.md, a row in the README table, and a clean-checkout smoke test. Collected skills keep their original license and attribution.

什么是 skill？

skill 是一个带 SKILL.md 的目录：YAML 前置元数据里写 name 和 description，可附带脚本和参考资料。description 告诉 agent 什么时候该用它，你只需用自己的话提需求。

参与贡献

每个 skill 一个顶层目录，SKILL.md 路径可移植，在 README 表格里登记一行，并从干净的检出跑通冒烟测试。收录他人的 skill 保留原许可与署名。
