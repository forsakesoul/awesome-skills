# 长任务续接

复用当前任务计划；只有状态无法由对话和 Git 恢复、或用户要求落盘时，在任务工作目录保存 checkpoint。记录目标/验收、仓库/分支/SHA、已完成事项、关键决策、阻塞与下一条证据或命令；不存凭据、Cookie、Token、可重放 URL 或原始日志。需要文件时读取 [checkpoint 模板](references/checkpoint.md)。

完成一个阶段或准备切换上下文时更新必要状态，继续执行尚可进行的授权工作。仅在明确的独立探索有价值且允许委派时使用子代理；不为每步固定派遣。

恢复时先读 checkpoint，再核对实时 Git、环境和外部任务状态。只重做已失效的检查；全部约定验收完成且缺口已明确处理才标记完成。checkpoint 记录历史，不能替代当前事实。

只剩外部结果时记录等待对象、下一条检查和继续/停止条件，优先使用当前宿主的完成通知或有界等待。无变化不反复轮询；切换去做其他任务时先留下恢复锚点。安排持久提醒须遵循宿主授权机制，等待不会自动授予发布或清理权限。

只有用户要求 Claude 原始会话备份或 `/clear` 操作时读取 [Claude 专属说明](references/claude-backup.md)。其他宿主使用其支持的续接机制，不要求重复确认已批准的阶段计划。
